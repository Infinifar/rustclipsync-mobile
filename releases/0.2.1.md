# RustClipSync Mobile 0.2.1

Android now supports Porter directly for capturing new clipboard text in the background. Shizuku 13+ remains supported. Start either manager in wireless debugging or ADB shell mode, then grant access in Settings → Sync → Background clipboard source. Porter takes priority when both managers are installed. Direct Porter support requires Porter 0.7.0-rc0 or later.

Temporary gateway errors preserve pending sync work for retry through the shared core.

This update supports Android 12+ on ARM64 and x86_64 and requires RustClipSync Server 3.0.0 with protocol 3. The official APK uses the existing signing certificate and Android versionCode 8 for in-place upgrades from 0.2.0.

中文：新增 Porter 原生后台剪贴板支持，同时保留 Shizuku。两个管理器都安装时优先使用 Porter。通过无线调试或 ADB 启动后，在「设置 → 同步 → 后台剪贴板来源」授权。临时网关错误会保留待处理同步以便重试。正式包沿用现有签名，支持从 0.2.0 覆盖升级。
