# RustClipSync Mobile 1.0.0

Standalone Android clipboard sync. Android 12+; one APK supports ARM64 and x86_64. Requires RustClipSync Server 3.0.0 / protocol 3, using shared core 0.4.0.

- Two-way, send-only and receive-only modes, with server-confirmed direction and Pause / Resume controls.
- Persistent pause state, immediate local transfer blocking and preservation of device pairing and encrypted inbox.
- Android Keystore-protected saved credentials, optional background operation and Shizuku ADB clipboard capture.
- Marked sensitive messages can be skipped, saved in the encrypted inbox or explicitly auto-written to the clipboard. Notifications hide their bodies by default.
- Automatic foreground receiving when background operation is enabled; task removal preserves the setting. Conflicting or expired uploads recover by safe skip without replacing the current clipboard.
- Core regex filters, English/Chinese, system/light/dark themes and the Omaclipsync S icon.

**Upgrade:** uses the same signing certificate as 0.1.5. Android versionCode increases from 6 to 7, supporting in-place upgrades while retaining app data. Old ephemeral debug APKs have a different certificate and cannot be overwritten by official releases; preserve needed data before any manual uninstall. No automatic uninstall or data deletion is performed.

Only enable one clipboard sync client on an Android device. Source applications may omit sensitivity flags; password-looking text is not treated as a reliable mark. HTTPS and encrypted local state are supported; end-to-end encryption is not implemented. Android/OEM background limits still apply. This release contains Android only; the iOS client remains in development.
