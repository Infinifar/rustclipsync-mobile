# RustClipSync Mobile 0.1.5

First formally signed standalone Android release. Android 12+; one APK supports ARM64 and x86_64. Uses core 0.4.0 / protocol 3 and RustClipSync Server 3.0.0.

- Pause / Resume stops sending and receiving, reports pause to the server and preserves direction, pairing and the encrypted inbox. Pause persists after reopening. Resume requires server confirmation before local access is restored.
- Keystore-encrypted saved connection credentials; independent background operation and Shizuku ADB clipboard capture.
- Sensitive messages: skip, encrypted inbox or explicit automatic clipboard write. Inbox notifications stay masked until an explicit unlocked reveal.
- Keep the background setting after task removal, receive with the UI open, and safely abandon conflicting or expired uploads without overwriting the clipboard.
- Omaclipsync S icon, white/black backgrounds, English/Chinese, shared core filters and direction controls.

**Migration from development APKs:** the earlier debug package uses the same application ID with a different signing certificate. Android cannot install this signed release over it. Preserve anything needed from the test app before manually removing that debug installation. Uninstalling deletes its Keystore credentials, pairing and inbox. No automatic uninstall or data deletion is performed. All later official releases retain the new release certificate for in-place upgrades.

Pausing clears unsent local candidates through core; already committed requests cannot be recalled. Copies made during pause are not sent later as fresh events. Device/OS service limits still apply; after process death, force-stop or reboot, reconnect in the foreground.
