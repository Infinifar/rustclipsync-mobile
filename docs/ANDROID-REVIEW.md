# Android 0.1.2 用户验收

设备：moto razr 60 u / Android 16 / MyUI。按用户要求，本轮视觉和真机检查交由用户。

1. 通知状态栏图标应为剪贴板轮廓，不是白色方块。
2. 解锁后展开有消息的收件箱通知，点“显示”：显示正文、按钮变“隐藏”，通知栏保持展开。
3. 点“隐藏”：恢复 **，通知栏保持展开；可多次切换。
4. 点“复制”：收起通知栏，全文复制并保留敏感标记；无需另外开启写入开关也可显式复制。
5. 锁屏/熄屏后预览仍隐藏；锁屏上的显示请求不泄露正文，先解锁再操作。
6. 设置中切换跟随系统、浅色、深色，重启应用后保留选择；跟随系统时响应系统明暗变化。
7. 展开/折叠、窄窗口、大字体、键盘弹出时，连接表单和按钮可滚动访问；三页职责清楚。

本轮仅执行源码静态检查与 GitHub 平台构建，不复用旧截图宣称新 UI 已视觉通过。
开发签名仍未固定，签名冲突时不要直接删除用户数据，详见 BUILD.md。

## 0.1.3 增补

- 通知副标题已移除；隐藏星号随屏幕宽度／字体变化，约占卡片宽度 2/3，与真实正文长度无关。
- 依次选双向、仅发送、仅接收，检查前台按钮和后台接收授权；仅发送不接收，切仅接收后旧上传不会重发。
- 过滤页测试关闭、黑名单、白名单与“同时过滤接收”；无效正则保存失败，旧配置保留；规则不会回溯清空已保存的收件项。
- 同步页 UUID 可选中，重连后保持不变；无需展示任何 token。
- 外观页选中文／English／跟随系统，检查三页、提示、通知及系统应用语言入口，重启后保持。
- 关于页检查更新及项目地址。私有仓库／未发布提示应区别于“暂无更高版本”；不会自动安装更新。

## 0.1.4 统一后台运行与 Shizuku

1. 升级后重新开启“后台运行”；设置中只出现这一项后台开关。敏感三策略为互斥选择，
   普通接收无需另一个开关。改选策略后重开应用，选择应保留。
2. 安装、以无线调试/ADB 模式启动 Shizuku 13+，在同步设置点击“请求 Shizuku 授权”。
   拒绝时不反复弹窗；允许后离开前台才连接来源。root 模式应明确提示改用 ADB。
3. 使用专门测试账户与非敏感合成文本。双向/仅发送下，后台从其他测试应用复制，应可推送；
   相同内容不循环上传。仅接收不推送，普通消息自动写入；仅发送不收消息。
4. 停止 Shizuku/撤销授权后，应显示不可用，已有内容续传和接收仍按 core 状态继续。
   回前台、锁屏、熄屏、关后台、关闭会话或划掉任务时不再读取新复制。超 256 KiB 不截断发送。
5. 接收合成“带敏感标记”消息：跳过不写入也无收件箱；加密收件箱保存且有独立通知；
   直接写入保留敏感标记且不生成新的收件箱通知。未标记文本按普通内容处理。
6. 若只有后台状态通知，查看收件箱页的实际条件、策略、最近同步结果及接收过滤提示。
   正确选择收件箱策略、允许通知与频道、方向含接收后，再发一条带标记的新合成消息；
   首次注册前的消息不会回放。已有项目可点击“显示收件箱通知”恢复。
7. 在 MyUI 再次检查显示/隐藏保持通知栏、复制收起、隐藏星号宽度和白色小图标；结果由用户反馈。

本轮仅编译 instrumentation，不自动运行上述真机或视觉步骤。Shizuku/真实 OS 适配器未经设备验证。


## 协议 3、图标与纯色背景

- 配套服务端 3.0.0，以非敏感测试账户检查连接、三种方向、重连和服务端窗口内的最近一条补发。
- 连接旧服务端时应提示协议版本不兼容，不使用旧广播或忽略方向确认。
- 桌面图标应为 Omaclipsync 的 S 形标识；系统浅色／深色背景分别白色／黑色，主题图标由启动器着色。
- 应用内跟随系统／手动浅色／手动深色的主背景应为白色或黑色，重启后仍保存选择。
- 三种敏感策略、Shizuku 调用者与锁屏保护仍按上面的清单验证；本轮没有自动启动模拟器或测试用户剪贴板。

## 凭据保存与 Shizuku（本轮设备验收）

- 旧版密码未保存，升级后先填写并成功连接一次。关闭会话、划掉任务或结束进程后重开，
  地址/账号/隐藏密码应恢复，尚未自动连接；切换语言后同样恢复。
- 点击保存并连接可重连原设备身份；连接失败不覆盖此前保存的凭据。
- 关闭会话后点击“删除已保存凭据”，重新打开字段为空；已有设备配对及加密收件箱保留。
  此操作不等同于服务器撤销令牌，也不提供跨账号重配对。
- Shizuku 通过无线调试/ADB 启动，点击授权并允许后，应显示“Shizuku 已成功授权”，
  即使背景来源空闲；开启后台运行、发送方向并回到其他应用后，来源才连接。
- 拒绝授权提示在 Shizuku 应用管理中允许；停止/重启 Shizuku 后状态应刷新，
  root 模式明确提示需切换 ADB。授权成功不代表已经启动后台同步或获得永久运行能力。

本轮不自动操作设备、剪贴板或真实账号；JVM 测试与 Actions 编译不代替以上实机步骤。

## 后台开关与旧事务修复验收

连接后启用后台运行，只保留独立 App 同步，用不同的新合成文本验证普通接收及敏感
收件箱。App 打开且有焦点时也应自动接收；退到桌面或划掉最近任务仍保留开关并
尝试继续当前同步。系统杀死进程/强行停止/重启后须重新点击“保存并连接”。
旧冲突/过期上传安全跳过，不以旧文字覆盖当前剪贴板；恢复当时远端消息也会跳过，
务必换一条新的测试内容再测。通知停止按钮和手动关闭后台开关仍会关闭后台设置。
